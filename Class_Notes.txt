	- DevOps ::::
		
		- DevOps is a Software Development Strategy, used to promote the collaboration between teams like Development Team and Operations Team to achieve Continuous Development, Continuous Integration, Continuous Testing, Continuous Delivery, Continuous Deployment and Continuous Monitoring in more automated fashion.

	Teams Involved :
	
		- Infra-Structure Management Team 
		- Application Development Team 
		- Testing Team
		- Release Management Team 
		- Production Monitoring Team 
		- Production Support Team 
		- IT Security

		- Stages of DevOps :
		
			- Continuous Development :
				- It is the capability of the Development Team to Continuously Develop the Application Source Code.
				- It is used to Improve Developer's Productivity, by using intuitive Tools like Modern IDEs, GIT, DVC Pipelines
				
				
			- Continuous Integration :
				- It is the capability of the Development Team to Continuously Integrate the Changes for further testing.
				
				- Automated :
				
					- Build
					- Packaging 
					- Unit Testing					
					- Promote to Test Environment
					- Notify thru Email
				
			- Continuous Testing :
				- It is the capability of the Testing Team to Continuously Test the Changes.
				
					- Selenium
					
					- MLFlow 
					- Monitoring Services 
					
					
			- Continuous Delivery/Deployment :::
			
				- Continuous Delivery 
					- It is process to release the changes to production with manual approvals
					- This ia applicable for Monolith Application Architecture
					- Leads to Application Downtime during Production Releases.

				- Continuous Deployment
					- It is process to release the changes to production without any manual approvals
					- Can be achieved only with the Micro-Service Based Application Architecture
					- With this we can achieve Zero-Downtime during Production Releases.
					
					
				- Docker,Kubernetes,KubeFlow,GitHub-Actions
